# 研发交付说明

对齐日期：2026-10-16。依据当前[视频运营.html](../../视频运营.html)的实际入口、保存函数、状态投影及服务适配器整理。适用于复现和继续开发此Demo；真实服务尚未交付，本文不虚构API地址、数据库或已完成的接入。

先读[产品需求](../产品/产品需求.md)确认范围，再用本文定位数据和实现。页面地址见[路由与状态](路由与状态.md)，样式见[界面与交互](../设计/界面与交互.md)，启动／检查／发布见[开发与验收](../维护/开发与验收.md)与[部署](../维护/部署.md)。本说明中的函数名均在唯一HTML内检索。

## 1. 交付与能力界线

| 项目 | 当前实现 | 研发衔接时需区分 |
| --- | --- | --- |
| 前端 | 单HTML、原生JS、Hash路由；Cloudflare静态托管 | 仓库是当前运行源码，没有业务服务端 |
| 文案、计划、回复建议 | 本地规则编排 | “AI生成”不代表已调用模型；自由提示词只执行已支持的关键词规则 |
| 新视频文件 | Canvas＋MediaRecorder，真实保存与下载 | 浏览器页面内录制；关闭弹窗可继续，刷新／关闭浏览器会中断 |
| 新画面 | 保存allowNewFootage布尔偏好 | 不生成新画面；勾选不阻止现有素材合成 |
| 配音 | 音色样音试听与设置快照 | 新任务未合入按文案生成的配音；语速／配音音量不能当成输出配音能力 |
| 背景音频／原声 | 上传音频实际循环混入；可保留原视频声音；内置选项使用合成旋律 | 与TTS配音分别处理 |
| 素材内容识别 | 适配器返回unavailable，允许人工完善 | 上传完成不等于内容识别或素材可用 |
| 登录／修改密码 | 登录只写会话标记；密码只做格式校验 | 不验证账号及旧密码，不创建账号，不保存或修改凭据 |
| 账号／草稿同步 | 本地配置、同步任务及回执校验结构 | 连接展示不是OAuth；同步适配器available=false，无真实平台草稿成功 |
| 客户咨询 | 样本会话、草稿、星标；符合样本连接条件时回复追加到本地 | 本地回复delivery为local-recorded、externalVerified=false，不是平台送达 |
| 报告／消息 | 根据本机记录即时整理 | 没有平台曝光／转化数据，没有服务端推送或不可变报表归档 |

普通创建页为“主题＋完整文案＋AI生成”，AI对话工作单仍为“描述需求／已有文案＋视频提示词”；对话内素材勾选和声音配置也没有完整复刻普通创建页。共同约束是素材、数量、时长及直接制作。保留当前差异，不能按“已完全统一”估算交付。

同步也有入口差异：从作品详情进入的普通表单固定该版本；独立AI对话不默认引用背景作品，先选视频、核对版本，再确认账号和文案。

## 3. 本地存储与关联

| 位置 | 内容／约束 |
| --- | --- |
| LocalStorage：video-ops-workspace-v1 | 主状态S，含当前成员、空间、业务实体、输入草稿和日志；不是数据库表定义 |
| IndexedDB：video-ops-media／files | 上传素材和新成片Blob；上传文件键为素材ID，成片键为版本ID |
| LocalStorage：video-ops-app-assistant-v2 | 按空间保存的对话、工作单和输入；旧video-ops-context-chat-v1迁移兼容 |
| LocalStorage：video-ops-notice-read-v1 | 消息已读映射，按空间及成员区分 |
| SessionStorage | video-ops-session-v1会话标记；来源、父级列表、滚动和播放器位置等临时状态 |

`media`可能为`媒体/…`相对路径、`embedded:素材ID`或`idb:键`，统一经mediaURL解析。`blob:`URL只是当前页面缓存，不是持久地址。静态站构建会提取内嵌媒体并改写URL，不改变原HTML及业务逻辑。

| 实体 | 主要字段与关系 |
| --- | --- |
| parks（企业空间） | id、name、type、location、description、facts、revision；brand含positioning／audience／keywords／copyRequirements／forbidden／revision；faqs及faqRevision独立维护 |
| assets | id、type、media、poster、duration、hash、tags、description、status；objectId／共享范围决定归属，分组和删除标记可按空间维护；使用assetInSpace检查，不能只比较objectId |
| plans → topics | 计划id／objectId／revision／status／start／end／autoCreate／productionPolicy；选题planId／objectId／date／brief／taskId／videoId；date是发布提醒时间 |
| drafts | S.drafts按ID保存；视频保留完整输入及素材／声音／数量／时长，计划草稿按计划逻辑处理；不得把所有draft条目都当视频草稿 |
| tasks → videos.versions | 任务objectId／status／stepIndex／progress／assets／script；可关联batchId、planId、topicId、draftId；成功后绑定videoId、versionId |
| videos | 作品id／objectId／version及versions数组；版本id／revision／media／poster／script／assets／声音设置／factsRevision等是历史快照；新成片只读 |
| publishing | 每条记录对应一个videoId＋versionId＋accountId；包含requestId、caption、status、syncState、draftId、syncReceipt；多账号创建多条记录 |
| accounts | 平台身份、objects可访问空间、ownerId、connection、draftSync；空间的平台账号选择另存spacePlatformAccounts |
| conversations | objectId／accountId／channel／messages／replyDraft／星标；既有来源关联按原记录保留，不推断新视频带来咨询 |
| members、roles | 成员objects授权空间＋roleId统一角色；角色global=true、objectId=null；旧spaceRoleIds及差异权限保留兼容，不直接全量覆盖 |
| logs | 操作人、时间、操作文字及可用的资源／空间元信息；当前本地日志，不是服务端审计凭证 |

普通commit先快照S，写状态及日志，LocalStorage保存失败时恢复快照。Blob先写IndexedDB，再提交对应业务记录；两种存储不是原子事务，可能留下无引用文件。研发接入服务端时需处理文件与业务提交的一致性，不能把本地回滚视为完整事务。

现有迁移包含主schema和模块独立标记，不能仅凭seed里的schema数值决定是否需要迁移。不得清空存储、反复追加样本或把历史发布改成新平台回执。不同域名／端口的数据不共用，目前没有完整导入导出和多端同步。

## 4. 字段与提交校验

以下是当前有效表单／提交路径的限制；正式接入时服务端应复核，不能只依靠HTML的maxlength和隐藏按钮。

| 场景 | 当前字段与限制 |
| --- | --- |
| 普通视频制作 | 主题必填、最长100字；文案必填、最长2400字；素材至少一份ready图片／视频；数量1–20整数，默认1；相同编排不足以产生指定条数时阻止并提示减少数量或补素材 |
| 视频设置 | 默认30秒，15／30／60或自定义10–120整数；竖9:16／横16:9；含图片时可选静态／推进／拉远；消除原声和字幕默认开启；allowNewFootage默认false |
| 内部剪辑输入 | 1–60段，总长10–120秒；每段至少0.5秒，视频起止不能超过原片，单段字幕最多70字；这是内部编排限制，不新增分镜编辑页 |
| 保存视频草稿 | 可以保存尚未填写完整的素材、主题和文案；时长、数量及空间／权限仍校验，制作时再执行完整校验；不能将草稿保存误做提交制作 |
| 配音／背景音频 | 音色可不配音，语速0.8／1／1.2，音量0–100；上传背景音频须在当前空间且ready，文件在当前浏览器可读取 |
| 上传与标注 | MIME为视频／图片／音频，单文件≤150MiB；视频≥1秒，音频≥0.5秒；SHA-256在归属空间去重；待标注素材必须有实际名称及标签才能采用 |
| 素材编辑 | 选择面板待标注名称≤80字、标签总长≤200字、说明≤1000字；素材详情编辑另校验最多20标签、每个≤20字；两处校验口径尚有差异，不能宣称全入口完全一致 |
| 计划 | 计划名称、首次发布提醒日期、目标必填；内容数量1–42整数；选题标题必填、最长100字；启用时开始日不得早于今天，未开始选题日期不得早于今天或开始日 |
| 业务介绍 | 业务类型必填≤80；地点≤160；说明≤500；目标客户≤120；特点≤300；关键词≤100；查看与编辑字段相同 |
| 常见问答 | 问题≤100、答案≤500；两者必填，不允许重复问题；confirmed绑定当前factsRevision，页面不重复放已确认标签 |
| 文案偏好 | 默认要求非空、≤500字；禁用词去重、按顿号连接总长≤200字；添加弹窗只改变当前表单，保存后持久化 |
| 个人／密码 | 昵称必填≤20且不能含尖括号，角色只读；当前密码必填，新密码8–64位且非全空白、不同于当前值，两次一致；仅格式校验 |
| 成员／角色 | 成员姓名必填≤20，账号3–100位、首位字母或数字、其余仅字母数字及_.@+-，忽略大小写查重；新成员至少一个空间并绑定有效统一角色。角色名称≤30、说明≤200，名称查重且至少一项当前可用权限；已绑定角色不可直接删除 |
| 同步／咨询 | 同步文案非空且至少一个当前空间可用账号；回复非空、≤3000字并校验会话范围、账号连接及回复权限 |

视频还校验资料／偏好版本、选题归属、禁用词及现有未确认条件规则。源码有园区面积、租金、许可等特定校验，它们是本地规则，不能据此认定已完成通用事实核查或行业知识服务。

## 5. 状态与执行

### 视频列表

列表合并输入草稿、未完成任务和成片，不直接遍历videos.status渲染。

| 列表状态／筛选值 | 判断依据 |
| --- | --- |
| 草稿／draft | 可恢复的制作前输入；绑定已开始任务后不重复占位 |
| 制作中／producing | tasks.status为queued、waiting、running |
| 制作失败／failed | 任务failed或历史cancelled；保留原错误、原状态；无有效媒体的作品也按失败处理 |
| 待同步／ready | 有版本media，当前版本各账号最新同步任务尚未全部核实完成，或尚无同步任务 |
| 已同步／synced | 当前版本各账号最新一条同步记录均完成；最新未完成记录会使作品回到待同步；旧published只按历史兼容映射，不生成新回执 |

成功链为：输入校验 → 保存制作任务 → 读取素材 → 录制 → 保存Blob → 提交作品／版本及任务succeeded → 列表待同步。新版本review为not_required、作品status为sync_pending。没有实际文件及成功保存，不能因动效、已录满时间或单个百分比改成成功。

stepIndex依次为0核对资料、1准备素材、2整理文案、3录制、4检查保存，成功后5。真实录制阶段的progress从0到100，不能把它解释成覆盖所有阶段的精确总耗时比例。

所有queued／waiting弹窗使用productionDisplayTask副本循环百分比与步骤；不写回任务，不真的检查或生成，不产生成功文件。running使用真实进度；failed／cancelled停止动画。无取消制作按钮。弹窗关闭只清理显示计时器，实际录制继续；刷新时running改failed并记录中断原因。

### 计划与多条制作

- 保存草稿不执行；保存并生成设status=active、productionPolicy=ahead、autoCreate=true、autoPublish=false，并为无videoId且未绑定既有任务的选题入队。审批、审核和自动制作勾选已撤下。
- planStatus将未来active显示待开始，周期内显示进行中，结束日已过则显示已结束；paused显示暂停，旧submitted按草稿解释。未来提醒日期不阻止提前制作，已结束计划不新增执行。
- 内容安排的处理反馈为本地规则计算及展示等待，不是异步模型任务；返回／空间或成员变化会使旧结果失效。选题文案在第二步完整预览，改标题会重算该选题文案。
- scheduler约每15秒只检查当前空间的planProduction队列。需要登录、视频创作以及制定计划或启停计划权限；有运行制作、多条制作、未保存输入、弹窗或选择器时不启动下一条。关闭进度弹窗后才可继续调度等待项。
- 暂停不强行中断正在录制的视频，只影响后续启动。无可用素材时保持waiting；资料／素材校验失败标failed。已绑定任务不会被每次调度重复创建，失败保留原任务供重试。
- 手动一次生成多条由startCutBatch／runCutBatch顺序执行，每条独立文件；刷新后剩余手动队列不自动由scheduler续跑。不要交付“任意队列断点自动恢复”的承诺。

### 同步与消息

publishing原始状态为sync_pending／syncing／synced／sync_failed／sync_unknown，另保留published、cancelled历史值。“待连接”是sync_pending＋waiting_connection等连接条件的展示，不是另一种视频列表状态。重载时syncing转sync_unknown，先核实结果，避免盲目重传。

draftSyncAdapter当前不可用。接入后的成功结果必须同时满足：status=synced、source=external、verified=true、persisted=true、非空draftId，且requestId／accountId／versionId匹配任务。reportSyncState还复核已保存回执。HTTP请求成功或本地保存任务都不够。当前用户可明确重复同步，每次建立新任务；同一表单连续点击受syncSubmitted保护，不等于跨设备服务端幂等。

消息不是单独写入的通知任务表：notificationFeed从失败制作、已生成版本、旧待启用计划、同步任务、最新待回复消息派生稳定ID，再叠加已读状态。只有全部／未读及视频制作／草稿同步／运营计划／客户咨询分类，没有待处理页签。读取消息不会完成业务事项。

## 6. 权限、并发与历史保护

日常数据按空间操作；角色为统一角色，成员objects决定可访问空间。保留旧的按空间差异授权，只有明确保存成员配置时才按当前表单调整。管理全局角色须核对所有受影响空间，不能仅检查当前空间。

权限组为business、assets、plans、videos、publishing、customers、analytics、accounts、settings。plans.approve目前代表启停与自动制作，不是审批流程；videos.review、customers.follow／assign／export已从新授权界面撤下。个人资料及密码属于自身设置，不要求团队设置权限。

业务资料使用编辑快照防止覆盖；修改type／location／description增加空间revision，修改品牌字段／文案偏好增加brand.revision，FAQ变更增加faqRevision；确认问答绑定事实版本。新创作核对对应快照，历史成片及文案不被改写。成员／角色同时检查已存配置、版本、关联成员、自锁、越权和平台账号职责。

commit只提供当前页面的本地保存回滚，部分表单另有快照冲突检测；不存在通用多窗口事务锁或服务端并发保证。生产接入需在服务端重新校验身份、空间、权限、版本及幂等，不能信任Hash里的objectId或前端隐藏操作。

## 7. 接入与验收边界

本轮继续保留现有可执行能力，不要求现在接入服务。下列是从当前Demo走向真实产品的衔接点，接口与部署架构仍需在具体接入任务中确定：

| 衔接范围 | 保留的产品契约／需补齐的能力 |
| --- | --- |
| 身份与数据 | 真实认证、成员账户、服务端空间权限、业务数据持久化；对象存储替代本机Blob；跨端一致性和失败恢复 |
| 文案／计划／素材理解 | 模型请求和结果结构、资料版本和来源、错误与重试；适配当前字段，不能因模型接入恢复审核或逐镜头确认 |
| 视频制作 | 若要求关页继续，需服务端任务、文件处理、队列、重试和可观测进度；若要求按音色输出，另接TTS及混音；新画面生成仍不属已实现范围 |
| 平台草稿 | 真实授权、上传、保存草稿及结果核验；以平台实际开放权限确定可行性，不自动执行公开发布 |

研发验收至少覆盖以下关键路径；这些是交接后的验收要求，不是本次已全部通过的测试报告：
