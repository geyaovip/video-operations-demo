# 视频运营界面规则

对齐版本：2026-10-19。本文只记录视频运营的页面组织、当前例外和实现取值；通用组件以[界面与交互规范](界面与交互.md)为准，其他项目按[UI复用指南](UI复用指南.md)建立自身适配表。

## 1. 项目边界

唯一运行源码为[视频运营.html](../../视频运营.html)，内联CSS、原生JS和初始数据，Hash路由，不引入框架或外置运行样式文件。本轮仅完善文档，不改变页面、业务数据、媒体或原有服务。

文档中通用规范的补充要求不表示当前Demo全站已经逐项验收。当前样式存在历史覆盖，应根据最终级联及实际视口读取，不从最早一段`.btn`、`.modal-header`等规则直接复制。

当前业务没有审批、视频审核、分镜确认、独立批量混剪、成片再编辑和定时同步。UI复用不能恢复这些入口。字段与状态详见[产品需求](../产品/产品需求.md)、[路由与状态](../技术/路由与状态.md)及[研发交付说明](../技术/研发交付说明.md)。

## 2. 应用框架与导航

企业空间入口在侧栏Logo下方、业务菜单上方，PC顶栏不重复；小于960px使用导航抽屉，同一选择器可切换／创建空间。PC侧栏224px、收窄72px；顶栏56px，手机避让顶部安全区。

头像菜单仅“设置”“退出登录”；手机菜单贴近抽屉底部头像上方，关闭头像菜单不关闭主抽屉。头像右侧昵称、角色左对齐。消息中心为独立页面，不恢复原简单弹窗。

右上询问AI是唯一常驻对话入口：PC星光＋文字，手机仅图标，透明底、无边框和阴影，悬停只变色。PC详情的返回在正文标题前，手机在顶栏；顶层工作台、日历等不显示无意义返回。

本项目列表查询按暂存→查询／Enter应用；日历月份／所属计划、报告类型、资源类型导航即时切换。业务列表默认20条，可选10／20／50，空列表不显示分页；首页摘要、日历、固定平台配置不分页。

## 3. 工作台与计划

### 工作台

- 顶部状态摘要为制作中、待同步、已同步、近30天咨询，不展示审核或已撤下的需求漏斗。
- 我的待办与最近作品PC等宽双栏，窄于960px转单列；最近作品展示视频创作靠前4条，允许草稿、制作中、失败等不同状态。
- 两个区块共用标题行：标题16／24／600；全部入口14／20／500，PC点击高度40px、手机44px。标题、入口、数量徽标不能改变彼此基线。
- 待办与作品入口按自身语义跳转，不重复展示制作进度大区块。
- 新空间准备项仅在onboarding空间且条件未齐时显示：非空业务说明、至少一份ready图片／视频、至少一个平台账号配置。条件全部齐备时整块隐藏，后来不满足可再出现；账号配置存在不等于真实授权。

### 计划与日历

计划统一新建入口，两步为计划设置→内容安排。数量手动输入1–42；第二步直接显示原位处理反馈及结果，不另开进度弹窗。处理完展示选题、完整文案、提醒日期／时间，返回保留输入并使旧处理结果失效。

“保存草稿”只保存，“保存并生成视频”保存后提前入队，不提交审批，不出现“审批通过后自动制作”勾选。日历只是发布安排提醒，不触发制作、同步或发布；月份使用左右翻页按钮。

计划卡片宽度≥1280px三列、768–1279px两列、≤767px单列，整卡进入详情，不重复放详情和排期按钮。卡片保留名称、状态、时间、目标与实际进度，不露内部版本号。

## 4. 视频创作与详情

列表合并输入草稿、制作任务和成片，显示草稿、制作中、待同步、已同步、制作失败。取消历史在列表按制作失败呈现，保留原始记录，不伪装仍在制作。草稿旁不显示“继续编辑”重复文案，整卡恢复输入。

卡片左大封面、右名称／来源／状态／平台／更新时间。当前卡片封面基础112×200px，手机104×184px，极窄屏有88×156px覆盖；手机列表也转相同信息卡。PC表格保持作品、状态、平台记录、更新时间四列。封面不拉伸，制作中卡片不堆百分比、执行步骤和失败长文。

创建页普通表单包括：素材、视频主题、完整视频文案与“AI生成”、数量、时长、比例、图片效果、配音与字幕、背景音频。“选择素材”始终位于已选集合末尾。主操作紧跟设置，手机底部固定并避让键盘和安全区。

只保留一键成片，数量1–20，默认1；默认时长30秒，15／30／60或自定义10–120整数。允许AI生成新画面可勾选，但只保存偏好，不真实生成。确认设置后直接制作，不核对分镜。

成片详情同屏显示播放器和完整文案，不恢复五项并列页签。存在来源计划才显示来源，多版本历史及去重素材按需展开；当前版本只有一处对应下载及有效同步入口。成片只读，旧编辑／审核链接归只读详情。

## 5. 制作进度弹窗

点击制作中记录打开共用弹窗；成功的单条任务已有实际媒体时直接定位作品版本，批次保留多条结果。弹窗只有关闭／查看有效结果等操作，无“取消本次制作”。

五步为检查业务资料、准备图片与视频、整理文案与字幕、生成视频文件、检查并保存视频。完成步骤对勾，当前转圈与说明，后续编号；真实运行任务显示真实阶段，真实录制阶段百分比不代表整个任务的精确总耗时。

queued／waiting记录（含预置及多条任务等待项）按用户指定，通过显示副本做10秒循环百分比、步骤对勾与转圈；不更改任务、不生成文件、不写成功结果。这是本项目的展示例外，**不得作为通用真实任务进度组件的业务实现复制**。减少动态效果时停止非必要循环。

关闭只清理显示计时，当前实际录制在页面内继续；刷新／关闭浏览器会中断，不代表服务器后台继续。真实失败、完成停止动效并保留相应结果。更新百分比复用已有节点，避免重置旋转动画和焦点。

## 6. 素材库与选择面板

素材库区分视频、图片、背景音频；创作选择面板还提供全部图片／视频视图。PC左侧分组，手机按需展开完整分组列表；支持搜索、新建、改名、排序和删除分组，删除分组不删除文件，资源归未分组。

本地素材先上传入库，核对名称、标签后再确认采用。上传取消采用仍保留库内文件；移除本次素材不删除文件。待选集合在确认前独立，取消不改原集合；跨查询、分组、分页保留勾选，重置搜索不清勾选。

选择面板当前PC最大宽约1080px并受视口约束。PC素材列表独立滚动，分页为列表后的普通布局区、非覆盖定位；手机滚到分页，底部确认区留出空间，不能压住最后一条和页码。

背景音频支持本地上传、标注、试听、选择、音量，并在实际录制中循环混入。素材内容识别适配器尚不可用，展示处理动效不能代表自动理解完成；人工标注才能成为可用素材。

## 7. 业务资料与设置

业务资料仅业务介绍、常见问答。查看与编辑同样展示业务类型、服务地点、说明、目标客户、特点、关键词；不隐藏已填写字段。常见问答去掉已确认标签，待确认／需核对提示和编辑确认仍保留。

设置统一从头像进入，分组包括个人资料、修改密码、文案偏好、成员与角色、操作记录。PC左目录右详情，默认个人资料；设置目录基础200px，768–1199px为174px，≤767px入口换行并展示内容。

个人资料默认只读，显示昵称、角色；编辑只改昵称，角色在成员与角色管理维护，不恢复岗位输入。密码显隐位于输入右侧内部，18px图标、44px点击区，透明无独立边框，与登录表单共用视觉。

默认文案要求为≤500字且非空的自由编辑文本，删除文案示例和咨询引导；禁用词为可移除标签，加号紧跟最后一项，点击弹窗添加，保存整个偏好后生效。

新增／编辑成员绑定统一角色和可访问空间；跨空间管理、越权、自锁、引用和冲突校验按研发契约保留。UI不因配置成员而假装创建真实登录账号。密码页仅格式校验通过后清空，未接入真实修改。

## 8. 咨询、同步、报告与消息

| 模块 | 当前界面规则 |
| --- | --- |
| 客户咨询 | PC会话／聊天双栏，窄屏列表→聊天；搜索、平台、评论／私信、星标。建议在输入下方左，发送右；删除重复回复标题和独立保存草稿按钮，保留离开保存与已有草稿恢复 |
| 草稿同步 | 从作品详情进入后固定视频／版本，只填文案、选账号、确认；不再选视频、设置定时或重复点“创建同步任务”；独立AI对话先选择作品再同步 |
| 账号管理 | 管平台身份、连接、检测、负责人和范围；不恢复独立同步列表或账号同步页签 |
| 运营报告 | ≥960px左列表右详情，无模块前返回；<960px列表→详情并恢复类型／分页。日报默认最新已结束日，周报上一完整周，月报上一完整月；无日期输入和查询重置 |
| 消息中心 | 独立页面，全部／未读，制作／同步／计划／咨询分类，查询、已读、事项跳转；不恢复已删除的待处理页签；已读不等于完成业务 |

同步成功依赖已核实真实回执，当前服务未接入；样本咨询回复只在本地追加，不表示外部送达。页面正式呈现，不额外放Demo、测试、事件注入或重置场景入口；接入边界写入内部交付文档。

## 9. AI对话工作区

PC面板最终有效宽为`min(560px, 100vw - 48px)`，高度最多760px且受视口限制；通用floating-chat旧规则中的440px／720px已被app-ai-panel覆盖，不能据此复刻。手机全屏。标题居中，左右等宽预留88px工具区，右侧新对话／关闭；长标题省略、历史选择可恢复。

打开默认新对话，可搜索历史，按空间恢复；四个快捷操作在输入框上方，PC自然排列、手机横向滑动。用户气泡随文字收缩，不重复显示发送方。Enter发送、Shift+Enter换行，中文组合确认不发送。

视频、计划、素材、报告、业务资料、草稿同步和咨询在对话工作单内完成，不自动引用背景记录，不丢背景未保存输入。普通创建页主题／文案，AI工作单仍有需求／已有文案模式和逐条提示词；素材选择及声音界面尚未完全统一，不宣称字段完全对齐。

工作单外壳基础18px内边距、16px圆角，手机14px、≤360px为12px；问答内卡PC16px、手机12px内边距、10px圆角，标题、移除、输入框均位于边框内并对齐。字段不贴边，外卡／内卡／输入三层不能叠成一条粗边框。

## 10. 当前实现例外与复用限制

| 项目 | 当前事实 | 后续处理 |
| --- | --- | --- |
| 基础CSS | 多轮覆盖并存 | 新项目取有效Token与交互，不复制全量CSS |
| 紧凑控件 | PC返回可36px，部分分页32／36px；手机主要入口44px | 通用新组件按40／44px基线，局部例外单列 |
| 手机字体 | 普通输入16px，部分查询控件14px，极窄顶栏17px | 按目标浏览器阅读与聚焦实测，不全局缩字 |
| 无草稿页面离开 | 当前沿用继续编辑／危险样式放弃离开 | 新项目区分放弃本轮输入与删除资源；本轮只记录，不改当前行为 |
| 服务能力 | 本地规则、录制及浏览器存储；无真实AI、TTS新配音、认证、同步、咨询收发 | 完整能力说明见数据与能力，不把UI成功态当外部验收 |
| 文档检查 | 语法、链接、媒体和交付包可以静态验证 | 不等于全站可访问性或所有响应式状态已验收 |

维护本项目按[开发与验收](../维护/开发与验收.md)执行，临时截图和日志放项目外，不新建旧验收／归档目录。
