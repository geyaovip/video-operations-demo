界面结构主要查看 DOC-01、DOC-05、DOC-06、DOC-09—DOC-15、DOC-19—DOC-22；PPT 中重点查看第 10—14 页产品画面。没有从登录后台、第三方文章或其他系统取得腾讯产品 UI。
