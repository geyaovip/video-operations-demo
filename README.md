# 视频运营

本地单HTML产品。入口为[视频运营.html](视频运营.html)，交付文件在[交付](交付/使用说明.md)，当前产品与实现规则见下方文档。

## 打开与使用

保持`视频运营.html`和`媒体/`相对位置，在本目录使用静态服务：

```sh
python3 -m http.server 8797 --bind 127.0.0.1
```

访问`http://127.0.0.1:8797/视频运营.html`。已有服务时直接访问；改变端口或域名可能切换浏览器本机存储。制作时可关闭进度弹窗，但需保持浏览器页面运行。

流程：业务资料与素材 → 一键成片／新建计划 → 生成视频 → 下载或同步到草稿箱 → 咨询与报告。当前不包含审批、视频审核、成片再编辑或定时同步。外部模型、认证、平台同步和咨询收发的实际边界见[数据与能力](文档/技术/数据与能力.md)。
