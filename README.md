# WEIBOT 视频运营 · 内容计划与视频制作工作台

面向门店内容运营场景的浏览器端应用原型，整合业务资料、素材管理、内容计划、视频制作与运营报告。项目采用单 HTML 运行结构，并通过 Canvas 与 MediaRecorder 在浏览器内合成可预览、可下载的视频文件。

[在线体验](https://weibot-video-operations-demo.pages.dev/) · [产品说明](文档/产品/产品需求.md) · [研发交接](文档/技术/研发交付说明.md) · [部署说明](文档/维护/部署.md) · [使用说明](交付/使用说明.md)

## 核心功能

| 模块 | 功能说明 |
| --- | --- |
| 业务资料 | 按当前企业空间维护业务信息，作为内容制作的上下文。 |
| 素材管理 | 管理图片、视频与音频，支持分组和内容标注。 |
| 内容计划 | 创建计划与制作草稿，按日历查看内容安排。 |
| 视频制作 | 组合已有媒体、文字及背景音频，实际生成独立视频文件。 |
| 成片管理 | 预览、下载及查看制作状态，已生成版本保持只读。 |
| 运营报告 | 根据当前空间已有记录，查看已结束自然周期的运营汇总。 |

典型流程：**填写业务资料 → 整理素材 → 创建内容计划或一键成片 → 预览并下载视频 → 查看运营记录**。

## 技术实现

- 使用原生 HTML、CSS 和 JavaScript，页面、业务逻辑及初始数据集中在一个运行文件中。
- 使用 Hash 路由组织模块，以 LocalStorage 和 IndexedDB 保存本机状态与文件。
- 使用 Canvas、MediaRecorder 和浏览器音频能力完成媒体合成。
- 通过 Cloudflare Pages 静态托管，运行时不需要业务服务器或数据库。
- 按稳定 ID 关联空间、素材、任务与作品，保留草稿、冲突校验和历史状态兼容逻辑。

## 本地运行

```bash
git clone https://github.com/geyaovip/weibot-video-operations-demo.git
cd weibot-video-operations-demo
python3 -m http.server 8797 --bind 127.0.0.1
```

打开 [视频运营工作台](http://127.0.0.1:8797/视频运营.html)。保持 `视频运营.html` 与 `媒体/` 的相对位置；页面本身无需安装 Node.js 依赖。

视频制作需要保持浏览器页面运行。关闭制作弹窗不会取消任务，但刷新或关闭浏览器会中断录制。不同端口、域名使用独立的浏览器存储。

## 检查与部署

```bash
python3 工具/检查交付.py --source-only --runtime-only
python3 工具/部署Cloudflare.py
```

部署前需完成 Cloudflare 授权。当前采用 Pages Direct Upload，**推送 GitHub 与发布站点分别执行**。原片与交付 ZIP 不进入 Git，克隆后的运行文件按 `runtime-only` 模式检查。

## 当前能力边界

浏览器内的素材管理与媒体合成是本地能力。真实模型、新画面生成、生产身份认证、平台草稿同步和咨询收发尚未接入；界面中的连接状态、预置记录或进度动画不能作为外部平台调用成功的证明。本地权限校验也不替代服务端授权。

详细说明见[数据与能力](文档/技术/数据与能力.md)、[开发与验收](文档/维护/开发与验收.md)和[素材与来源](文档/维护/素材与来源.md)。
