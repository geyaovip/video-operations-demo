# 视频运营使用说明

将交付包完整解压后，保留`视频运营.html`与`媒体/`相对位置。所有业务页面在同一HTML内，没有安装框架或业务后端的前置要求。推荐使用固定域名和端口的静态服务访问；文件直开不是本轮验证方式。

本地可在解压目录执行：

```sh
python3 -m http.server 8797 --bind 127.0.0.1
```

打开`http://127.0.0.1:8797/视频运营.html`。已有同端口服务时直接访问，不重复启动。

1. 先完善业务介绍、常见问答和素材；素材支持视频、图片、背景音频。
2. 一键成片选择素材、填写主题及文案、设置数量后生成；也可保存输入草稿。
3. 新建计划确认内容安排后，保存并提前生成视频。日历仅提醒发布安排，不触发制作。
4. 生成的视频为待同步，只读预览、下载或选择同步到平台草稿箱。当前未接入真实同步服务，保存任务不表示平台已保存草稿。
5. 查看咨询、消息和已结束周期的运营报告。设置统一从左下头像进入。

记录和上传／生成文件属于当前浏览器及访问来源，不自动跨设备同步。制作期间可关闭进度弹窗，需保持浏览器页面运行；刷新或关闭浏览器会中断录制。需要留存的成片请下载。

当前文案／建议采用本地规则；允许AI生成新画面仅保存偏好。真实模型、认证、密码修改、平台同步、咨询收发和服务器后台均未接入。内置排队记录的循环动效不代表真实执行。
